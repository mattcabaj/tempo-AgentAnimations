How it works

A function is what the agent is doing: reveal, thinking, tool use, waiting, complete. A function's states are its animation phases (intro, loop, outro), so a continuous function can hold its loop for as long as it runs. One-shots and Waiting need no separate states. Everything ships as scalable animated SVG, and every file shares one frame.

One frame for every file

  • All nine files use the same square frame: viewBox="0 0 880 880".
  • The resting logo is centered in it at 440, 440, and each animation is balanced around that point.
  • Nothing is clipped: every file stays inside the frame, and thinking-loop runs edge to edge. The frame has no built-in margin, so add padding in your layout.
  • Turn on Guides above to see the frame edge, resting logo and center.

Seamless handoff

  • Each intro's last frame equals its loop's first frame, and each outro starts on that same frame and ends on the logo.
  • Each loop starts and ends on the same frame, so swapping the source at any boundary is seamless.

Sizing & format

  • SVGs are vector, so one file scales to any size. Set width/height or CSS on the frame.
  • The frame size is the whole 880 unit square. The resting logo fills about 42% of it, so a 48px frame shows a logo about 20px wide.
  • Recommended minimum frame: 48px. Below about 24px, use a goo-off variant with clean circles.
  • Animated SVG (SMIL) plays in browsers. For email, decks or social, request GIF or MP4.

Monochrome

  • Colour is baked into the two-tone files, so page CSS can't recolor them. Use the matching files in svg-exports-mono for a one-colour mark. Same names, same motion and frame.
  • Default is navy #002755. Set --tempo-color on the element or a parent (when inlined) to change it, for example white on dark. Used as an <img>, the file stays navy.
  • Switch Colour above to preview it. The green hand-offs in Thinking and Tool use are invisible in mono, so those functions read as motion only.
